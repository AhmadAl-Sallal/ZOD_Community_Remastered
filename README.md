# ZOD Community Remastered 2026

A modernized community edition of ZOD Engine, based on the classic real-time strategy game Z (1996) by The Bitmap Brothers.

This project preserves the original gameplay while introducing improvements to graphics, AI, pathfinding, combat, controls, multiplayer, and overall stability.

## 🎮 Download

[Download ZOD Community Remastered v1.0.1](https://github.com/AhmadAl-Sallal/ZOD_Community_Remastered/releases/tag/v1.0.1)

Download "ZOD_Community_Remastered.zip", extract the archive, and launch the game on Windows.

## ⭐ Features

- 35 campaign missions, reviewed and tested.
- Enhanced graphics and terrain.
- Improved AI, pathfinding, and combat behavior.
- Rebalanced units and production times.
- Improved unit selection and controls.
- Expanded multiplayer interface supporting up to 8 players.
- Standalone Map Editor.
- Numerous bug fixes and stability improvements.
- 1280×720 resolution support.
